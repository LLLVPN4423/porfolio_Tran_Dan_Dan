# Hướng dẫn cho AI Agent

**Trước khi sửa code:** đọc [`PROJECT_CONTEXT.md`](./PROJECT_CONTEXT.md) — đủ để hiểu dự án, không cần quét toàn repo.

**Sau mỗi lần làm việc (hoặc trước khi push):** thêm một mục vào [`AGENT_CHANGELOG.md`](./AGENT_CHANGELOG.md) (ngày, việc làm, file đụng tới, commit nếu có).

**Deploy:** push lên nhánh `main` → GitHub Actions deploy GitHub Pages (chỉ khi user yêu cầu hoặc đã quen workflow deploy của repo).

**Không commit** (trừ khi user yêu cầu rõ): `_sync_drive_assets.mjs`, `_force_profile_sync.mjs`, `_build_portfolio_galleries.mjs`, `_assets_manifest.json`, `_drive_list.html`, `_sample_folder.html`, `_gen_grids.mjs`.
